五、快速开始
================================================================================

1. 安装依赖
   npm install

2. 配置环境变量
   cp .env.example .env.local
   # 编辑 .env.local 填写 OPENAI_API_KEY 和 AMAP_API_KEY

3. 启动服务
   npm run dev

4. 测试 API
   npm run test:api
