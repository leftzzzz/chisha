### 4.2 关键类型定义

在 `types/index.ts` 中需要定义：

```typescript
// 基础类型
type Location = { lat: number; lng: number; address?: string }
type Restaurant = {
  id: string
  name: string
  cuisineType?: string
  rating?: number
  distance: number
  address: string
  phone?: string
  openingHours?: string
  averagePrice?: number
  location: Location
  source: 'amap' | 'osm'
}

// API 请求/响应
type UnderstandRequest = { query: string; location: Location }
type UnderstandResponse = { success: boolean; data?: ParsedRequirement; error?: string }

type SearchRequest = {
  keywords: string[]
  location: Location
  distance?: number
  cuisineTypes?: string[]
  priceRange?: [number, number]
}
type SearchResponse = { success: boolean; data?: { restaurants: Restaurant[] }; error?: string }

// 应用状态
type AppStep = 'INPUT' | 'UNDERSTANDING' | 'SEARCHING' | 'READY' | 'SPINNING' | 'RESULT' | 'ERROR'
type AppState = {
  step: AppStep
  query: string
  location: Location | null
  restaurants: Restaurant[]
  selectedIndex: number
  error: string | null
}

// 历史记录
type TurntableRecord = {
  id: string
  timestamp: number
  originalRequest: string
  location: Location
  selectedRestaurant: Restaurant
  allRestaurants: Restaurant[]
}
```

## 八、风险识别和应对

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| **OpenAI API 超时** | 无法理解需求 | 8s 超时 + 自动降级到简单分词 |
| **高德地图无结果** | 搜索失败 | 自动降级到 OSM 搜索 |
| **两个地图都无结果** | 无法推荐 | 扩大搜索距离 + 友好错误提示 |
| **用户定位失败** | 无法自动定位 | 提供手动输入地址选项 |
| **转盘动画卡顿** | 用户体验差 | CSS Animation + GPU 加速 (transform) |
| **API 密钥泄露** | 成本超支、安全 | 使用 Vercel 环境变量，不提交到 git |
| **localStorage 容量** | 历史记录丢失 | 限制 100 条记录，超过后删除最早的 |
