**文件**: \`app/api/understand/route.ts\`

**功能**:
- 接收用户自然语言需求 + 位置
- 调用 OpenAI GPT-5.2 解析需求
- 提取关键词、菜系、价格范围、搜索半径
- 错误降级：超时时使用简单分词

**测试用例**:
- 正常请求 ✓
- 参数验证（字符长度、位置格式）✓
- 超时降级 ✓
- LLM 返回错误 ✓

**交付物**: 完整的 understand API + 单元测试

#### 2.2 餐厅搜索接口
**文件**: \`app/api/search/route.ts\`

**功能**:
- 接收搜索参数（关键词、位置、距离、菜系、价格）
- 优先调用高德地图 POI 搜索
- 如果无结果，降级到 OpenStreetMap Overpass API
- 返回最多 8 家餐厅数据
- 数据转换和聚合

**测试用例**:
- 高德正常返回 ✓
- 高德无结果 → OSM 降级 ✓
- 价格过滤 ✓
- 距离计算（OSM）✓

**交付物**: 完整的 search API + 数据转换器

#### 2.3 地理编码接口
**文件**: \`app/api/geocode/route.ts\` 和 \`/geocode/reverse/route.ts\`

**功能**:
- POST /api/geocode：地址 → 经纬度
- POST /api/geocode/reverse：经纬度 → 地址
- 调用高德地图 API
- 格式化返回数据

**交付物**: 两个地理编码 API

## 五、风险和缓解策略

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| OpenAI API 超时 | 无法理解需求 | 实现降级策略，使用简单分词 |
| 高德地图无结果 | 搜索失败 | 使用 OSM 作为备选 |
| OSM 和高德都无结果 | 无法推荐 | 显示友好错误提示，允许重试 |
| 定位失败 | 用户无法输入位置 | 提供手动输入地址的选项 |
| 转盘动画卡顿 | 用户体验差 | 使用 CSS 动画 + GPU 加速 |
| 浏览器不支持某特性 | 功能不可用 | Feature detection + polyfills |

## 七、关键决策

### 1. 状态管理选择：React Context vs Redux
**决定**: React Context + useReducer
**理由**: 应用复杂度适中，无需额外依赖，内置方案足够

### 2. 样式方案选择：CSS-in-JS vs Tailwind vs CSS Modules
**决定**: Tailwind CSS
**理由**: 快速开发、响应式支持完美、文件大小小

### 3. 地图库选择：Leaflet vs Mapbox vs Google Maps
**决定**: Leaflet + OpenStreetMap
**理由**: 开源免费、轻量级、支持自定义标记

### 4. 数据存储：localStorage vs 后端数据库
**决定**: localStorage（MVP 阶段）
**理由**: MVP 阶段无需用户认证，简化部署

### 5. 转盘实现：Canvas vs SVG vs CSS
**决定**: CSS + JavaScript 计算
**理由**: 性能最优、易于维护
