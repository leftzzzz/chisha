# ChiSha 用户指南

ChiSha 根据自然语言需求和当前位置推荐附近餐厅，再用可编辑转盘帮助你完成选择。

## 开始搜索

### 1. 选择位置

搜索附近餐厅前必须有有效位置：

- 允许浏览器定位；或
- 输入地址并等待系统完成地址解析。

浏览器拒绝定位时仍可使用手动地址。切换位置后，新搜索使用新位置；从分享链接加载的
转盘不包含真实位置，开始新搜索前需要重新选择。

### 2. 描述需求

直接输入日常表达即可，例如：

- `附近两公里想吃不辣的川菜`
- `人均 80 以内，适合四个人聊天`
- `想吃寿司，不要商场里的店`
- `随便推荐，但最好还在营业`

明确的距离、预算、营业状态和排除项会作为本次目标约束。地图分类或历史偏好不会覆盖
你当前说出的限制。

输入不能为空；一轮消息最多 500 个字符。

## 搜索与追问

提交后界面会流式显示理解、搜索和验证进度。同一步可能并行搜索多个方向，因此看到的
关键词和结果数量会逐步汇总。

当目标范围不明确或需要授权放宽时，系统会暂停并提问：

- 点击选项会按该选项的稳定 id 继续；
- 也可以输入自由文本补充；
- 回答会在同一个匿名 Agent 会话中续跑。

如果模型、地图服务、容量调度或配置不可用，界面会显示实际失败。系统不会用本地菜名
词表假装已经理解或验证成功。

## 主推荐与候补

搜索结束后结果分为两类：

- **主推荐**：通过当前目标、硬约束和证据准入，可直接进入转盘。
- **候补**：可能相关但存在证据不足、字段未知或未授权放宽，只显示在候补区。

候补不会自动补满转盘。只有你在“管理选项”中明确加入，它才会进入转盘。推荐说明和
未满足约束会保留在结果旁，不要把候补标签理解为已经满足全部要求。

## 管理转盘

转盘支持 3 至 8 个选项，餐厅和自定义文字共享数量上限。

在管理面板中可以：

- 把当前餐厅移入候补；
- 把候补餐厅加入转盘；
- 恢复之前移除的餐厅；
- 在当前位置附近直接搜索并添加餐厅；
- 添加“在家做饭”等纯文字选项；
- 删除自定义选项。

同一物理地点不会重复加入。少于 3 个选项时不能转动，界面会要求添加选项或重新搜索；
达到 8 个后必须先移除一个才能继续添加。

## 转动与结果

准备好后点击转动按钮。动画结束时指针对应的选项就是本轮结果：

- 再来一次会复用当前转盘，不重新搜索；
- 移除结果会更新转盘，必要时回到输入状态；
- 餐厅结果可以在地图中查看位置与详情；
- 自定义文字选项只作为选择结果，不会生成虚构餐厅信息。

桌面端地图作为主要空间视图，点击转盘餐厅会聚焦地图；移动端点击餐厅会打开底部详情。

## 分享

选中结果后可以生成海报或复制分享链接。分享链接包含：

- 当前查询文字；
- 转盘餐厅；
- 自定义选项。

它不包含当前位置、匿名 Cookie、Agent session 或 trace。任何拿到链接的人都能看到链接中
编码的查询和餐厅，请不要分享敏感文字。

接收者打开链接后可以恢复并转动同一组选项；若要重新搜索附近餐厅，必须选择自己的位置。

## 历史记录

每次转盘从转动进入结果时，会把本轮保存到当前浏览器的 `localStorage`：

- 查询和位置；
- 参与转盘的餐厅与自定义选项；
- 手动移除的餐厅；
- 最终选中结果。

历史最多 100 条，按时间倒序显示。同一查询、相同坐标且 30 分钟内的“再来一次”只保留
最后一条结果。

历史页支持：

- 按查询、餐厅名称、菜系或自定义选项搜索；
- 查看详情与统计；
- 删除单条或清空全部；
- 导出 JSON 备份；
- 导入以前导出的记录；
- 再次使用一条记录恢复转盘。

再次使用只恢复转盘内容，不恢复过期的 Agent 会话、候补、trace 或旧证据状态。

## 本地数据与会话数据

- 转盘历史只存在当前浏览器。清除站点数据、无痕窗口关闭或浏览器拒绝存储后可能丢失。
- Cloudflare 公开部署中的 Agent 多轮会话保存在 D1，可能包含位置、对话和搜索运行状态，
  并由签名匿名 Cookie 限制访问。
- 不同浏览器、设备或清除 Cookie 后不能继续原会话。
- 导出历史前请检查其中的位置和查询文字；导出文件由你自行保管。

自建部署者的数据责任和安全设置见 [安全说明](../SECURITY.md)。

## 常见问题

### 搜索按钮不能使用

确认输入不为空，并且已经获得有效位置。分享转盘中的“来自分享”占位位置不能用于搜索。

### 为什么只有少量主推荐

系统不会为了凑数把证据不足、明确违规或未授权放宽的餐厅提升为主推荐。可以查看候补和
未满足约束，修改需求，或手动把愿意接受的候补加入转盘。

### 为什么不能继续追问

会话可能已经过期、Cookie 已清除、请求正在同一会话中运行，或服务暂时拥塞。404 不会
区分会话不存在与不属于当前浏览器；429/503 可按界面提示稍后重试。

### 地图空白

这通常是部署者没有配置 Web 端 JS Key、安全密钥或域名白名单。餐厅文字列表仍应保留；
自建部署请检查 [部署指南](./DEPLOYMENT.md)。

### 历史没有保存

浏览器可能禁用了 `localStorage`、存储已损坏或容量不足。检查浏览器站点权限；重要记录先
导出备份。
