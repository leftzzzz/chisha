## 快速开始

### 首次使用

1. **打开应用**
   - 访问网站首页
   - 应用会自动加载

2. **允许位置访问**（推荐）
   - 点击"自动定位"按钮
   - 浏览器会请求位置权限
   - 点击"允许"以获得最准确的推荐

3. **开始搜索**
   - 在搜索框输入您的需求
   - 例如："附近的川菜"、"便宜的火锅"
   - 点击搜索按钮或按 Enter

4. **转盘抽选**
   - 查看搜索到的餐厅列表
   - 点击"开始抽选"按钮
   - 等待转盘停止
   - 查看选中的餐厅

## 核心功能

### 1. 智能搜索

**功能说明**：
使用自然语言描述您想吃什么，系统会智能理解并搜索合适的餐厅。

**支持的输入方式**：
- 菜系类型："川菜"、"粤菜"、"日本料理"
- 价格范围："便宜的"、"高档的"、"实惠"
- 距离限制："附近"、"1公里内"、"不超过500米"
- 组合查询："附近便宜的川菜"

**示例**：
```
✓ "想吃火锅"
✓ "附近的咖啡店"
✓ "2公里内便宜的川菜"
✓ "高档的日本料理"
✓ "实惠的快餐"
```

### 2. 位置服务

**自动定位**：
- 点击"自动定位"按钮
- 允许浏览器访问位置
- 系统会自动获取您的当前位置

**手动输入地址**：
- 点击"手动输入"
- 输入详细地址（如"北京市朝阳区"）
- 系统会将地址转换为坐标

**位置显示**：
- 在界面顶部显示当前位置
- 显示城市和区域信息
- 可随时更改位置

### 3. 转盘抽选

**使用步骤**：

1. **搜索餐厅**
   - 输入需求并搜索
   - 等待搜索完成

2. **查看结果**
   - 查看搜索到的餐厅列表
   - 每个餐厅显示：
     - 名称
     - 地址
     - 距离
     - 评分（如有）

3. **开始抽选**
   - 点击"开始抽选"按钮
   - 转盘开始旋转（3-5秒）
   - 指针会指向随机选中的餐厅

4. **查看详情**
   - 转盘停止后显示选中餐厅
   - 查看详细信息
   - 可在地图上查看位置

5. **其他操作**
   - "再来一次"：重新抽选
   - "重新搜索"：返回搜索界面

### 4. 历史记录

**自动保存**：
- 每次抽选结果自动保存
- 最多保存 100 条记录
- 超过限制自动删除最早记录

**查看历史**：
- 点击右上角"历史"按钮
- 查看所有历史记录
- 显示：
  - 搜索关键词
  - 选中的餐厅
  - 选择时间
  - 位置信息

**管理历史**：
- **删除单条**：点击记录右侧的删除按钮
- **清空全部**：点击"清空历史"按钮
- **导出数据**：点击"导出"按钮（下载 JSON 文件）
- **导入数据**：点击"导入"按钮（上传 JSON 文件）

**历史统计**：
- 总记录数
- 最常去的餐厅
- 最常搜索的菜系
- 平均搜索频率

## 详细使用说明

### 搜索技巧

#### 1. 精确搜索

使用具体的菜系或类型名称：
```
✓ "川菜"
✓ "火锅"
✓ "咖啡店"
✓ "烧烤"
```

#### 2. 价格筛选

使用价格相关词汇：
```
✓ "便宜的餐厅"
✓ "实惠的川菜"
✓ "高档的日本料理"
✓ "性价比高的火锅"
```

#### 3. 距离控制

指定搜索范围：
```
✓ "附近的餐厅"（默认 2 公里）
✓ "1公里内的咖啡店"
✓ "500米内的快餐"
✓ "3公里以内的火锅"
```

#### 4. 组合查询

综合使用多个条件：
```
✓ "附近便宜的川菜"
✓ "2公里内高档的日本料理"
✓ "500米内实惠的快餐"
```

### 位置管理

#### 自动定位

**优点**：
- 最准确的位置
- 实时更新
- 自动搜索附近餐厅

**步骤**：
1. 点击"自动定位"
2. 允许位置权限
3. 等待定位完成
4. 确认位置信息

**注意事项**：
- 需要浏览器支持地理位置 API
- 室内定位可能不够准确
- 需要网络连接

#### 手动输入

**使用场景**：
- 不想分享位置
- 搜索其他地区餐厅
- 自动定位不准确

**输入格式**：
```
✓ "北京市朝阳区"（推荐）
✓ "上海市浦东新区"
✓ "深圳市南山区"
```

**提示**：
- 越详细越准确
- 包含市、区信息
- 避免使用简称

#### 位置缓存

**说明**：
- 位置会缓存 30 分钟
- 避免频繁定位
- 节省流量和电量

**手动刷新**：
- 点击位置旁的刷新图标
- 重新获取当前位置

### 转盘使用

#### 转盘显示

**元素说明**：
- **扇形区域**：每个餐厅占据一个扇形
- **颜色**：不同餐厅使用不同颜色
- **指针**：红色三角形指针
- **餐厅名**：扇形内显示餐厅名称

#### 抽选过程

**动画说明**：
- 转盘顺时针旋转
- 速度先快后慢
- 持续 3-5 秒
- 停止时有减速动画

**公平性**：
- 使用随机算法
- 每个餐厅概率相等
- 结果不可预测

#### 结果展示

**信息包含**：
- 餐厅名称
- 详细地址
- 距离（米/公里）
- 评分（如有）
- 地图位置

**操作选项**：
- **再来一次**：重新抽选（不改变列表）
- **重新搜索**：返回搜索界面
- **查看地图**：在地图上查看位置
- **保存记录**：自动保存到历史

### 历史功能

#### 查看历史

**显示内容**：
```
搜索关键词: "附近的川菜"
选中餐厅: "川味轩"
地址: "xx路xx号"
距离: 500米
时间: 2025-12-14 14:30
```

**排序方式**：
- 按时间倒序（最新在前）
- 可选按距离排序
- 可选按餐厅名称排序

#### 统计信息

**显示数据**：
- 总记录数：100 条
- 最常选择：川菜（20 次）
- 最近选择：今天 14:30
- 平均距离：1.2 公里

**图表展示**：
- 菜系分布饼图
- 时间分布柱状图
- 距离分布曲线

#### 数据管理

**导出功能**：
1. 点击"导出"按钮
2. 选择导出格式（JSON）
3. 下载到本地
4. 可用于备份

**导入功能**：
1. 点击"导入"按钮
2. 选择 JSON 文件
3. 上传并导入
4. 自动合并去重

**清空功能**：
1. 点击"清空历史"
2. 确认操作
3. 所有记录删除
4. **不可恢复**

## 常见问题

### Q: 搜索没有结果怎么办？

**原因**：
- 关键词太具体
- 位置不准确
- 该地区餐厅较少

**解决方法**：
1. 使用更宽泛的关键词
2. 扩大搜索范围
3. 更换搜索位置
4. 使用基本菜系名称

### Q: 定位不准确怎么办？

**解决方法**：
1. 到室外获取位置
2. 检查浏览器权限
3. 使用手动输入地址
4. 检查网络连接

### Q: 转盘一直转不停？

**可能原因**：
- 网络问题
- 浏览器卡顿
- 设备性能不足

**解决方法**：
1. 刷新页面
2. 清除浏览器缓存
3. 使用其他浏览器
4. 检查网络连接

### Q: 历史记录丢失？

**原因**：
- 清除了浏览器数据
- 更换了设备
- 使用了隐私模式

**预防措施**：
- 定期导出历史记录
- 不使用隐私模式
- 不清除网站数据

### Q: 某些餐厅找不到？

**可能原因**：
- 餐厅未在地图上标注
- 关键词不匹配
- 超出搜索范围

**建议**：
- 使用餐厅准确名称
- 扩大搜索范围
- 尝试其他关键词

## 故障排除

### 应用无法加载

**检查清单**：
- [ ] 网络连接正常
- [ ] 浏览器版本最新
- [ ] JavaScript 已启用
- [ ] 没有使用广告拦截器

**解决步骤**：
1. 刷新页面（Ctrl/Cmd + R）
2. 强制刷新（Ctrl/Cmd + Shift + R）
3. 清除缓存
4. 重启浏览器

### 搜索失败

**错误提示**：
- "API 调用失败"
- "网络错误"
- "超时"

**解决方法**：
1. 检查网络连接
2. 等待几秒后重试
3. 简化搜索条件
4. 联系技术支持

### 转盘动画卡顿

**优化方法**：
1. 关闭其他标签页
2. 清理浏览器缓存
3. 重启浏览器
4. 更新显卡驱动

### 地图不显示

**检查**：
- 网络连接
- 浏览器权限
- JavaScript 错误

**解决**：
1. 刷新页面
2. 检查浏览器控制台
3. 尝试其他浏览器

## 隐私和数据

### 数据存储

**本地存储**：
- 历史记录存储在浏览器 LocalStorage
- 位置信息临时缓存（30 分钟）
- 搜索偏好（可选）

**服务器存储**：
- **不存储**任何个人数据
- API 调用日志仅用于调试
- 不会上传历史记录

### 位置隐私

**使用原则**：
- 仅在搜索时使用
- 不会上传到服务器
- 可随时拒绝授权
- 可使用手动输入替代

**权限管理**：
- 浏览器权限设置
- 可随时撤销
- 每次请求需确认

### 数据导出

**完整性**：
- 导出包含所有历史数据
- JSON 格式，易于阅读
- 可在其他应用中使用
